# sistem-informasi-jemaat-gpm-Waru
istem Informasi Jemaat (SIJ) adalah solusi digital terintegrasi yang mentransformasi manajemen administrasi tempat ibadah menjadi lebih modern dan transparan. Melalui sistem ini, pengurus dapat mengelola data keanggotaan, inventaris, dan keuangan secara real-time, sementara jemaat menikmati kemudahan akses informasi serta pelayanan administratif
